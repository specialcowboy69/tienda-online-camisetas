# Consent-gated GA4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Medir visitas del storefront con `G-4JDZCBK8SY` únicamente después de aceptar, permitiendo rechazar y retirar el permiso sin romper la compra.

**Architecture:** Política pura de consentimiento y páginas, adaptador único de gtag y componente cliente global para ajustes. Las páginas públicas registran metadatos sanitizados después de validar su contenido, sin nuevas lecturas de catálogo. La entrega queda apagada por defecto; la activación pública es una acción separada.

**Tech Stack:** Next.js 15 App Router, React 19, TypeScript, Vitest en Node, gtag.js y Playwright del runtime de Codex para verificación; sin dependencias nuevas del producto.

**Spec:** [2026-10-13-ga4-consent-design.md](../specs/2026-10-13-ga4-consent-design.md), aprobada el 13 de octubre de 2026.

Estado: plan preparado para revisión; ninguna tarea de implementación ejecutada.
Método recomendado: ejecución nativa secuencial y revisión independiente final;
las tareas comparten interfaces y no conviene escribirlas en paralelo.

## Global Constraints

- `G-4JDZCBK8SY`; `NEXT_PUBLIC_GA4_ID` y `NEXT_PUBLIC_ANALYTICS_ENABLED`, habilitante exactamente `true`; apagado por defecto.
- Consent Mode básico: cero carga/pings antes de aceptar o tras rechazar; todas las regiones con la misma regla.
- Solo `analytics_storage` puede concederse; `ad_storage`, `ad_user_data`, `ad_personalization` permanecen `denied`.
- Google Ads, Signals, personalización, User-ID, enhanced conversions y conversiones de compra fuera de alcance.
- LocalStorage `ncc.analytics-consent.v1`, versión 1, elección y fecha; 180 días para ambos resultados, sin renovación por visita.
- Cookies de esta integración: 180 días, sin renovación automática y prefijo propio; no tocar cookies ajenas.
- Solo `/`, `/products` y PDP válidos; ningún dato de formulario, query, hash, UTM o identificador de pago/pedido.
- Texto visible en inglés; rechazar no impide comprar; cambiar ajustes no recarga ni pierde carrito/formulario.
- No tocar el modelo de catálogo, precios, envíos, Stripe, Printful, emails, alertas ni credenciales. Stripe Tax off y NO-GO sin cambios.
- No publicar borradores legales incompletos; no fusionar automáticamente la rama legal; no activar servicios por aprobar este plan.
- Windows/PowerShell, Node >=22.12.0, ramas `codex/`, archivos explícitos en commits; no incluir `.superpowers/`.

## Review Focus

1. Retirada mientras gtag está cargando: ningún callback tardío puede configurar/enviar; tarea 2.
2. Preferencia corrupta, futura, caducada o inaccesible: denegar, no bloquear compra; tareas 1 y 3.
3. Cambio hacia ruta sensible con etiqueta ya cargada: pausar también eventos automáticos, no solo page_view; tareas 2 y 4.
4. Consentimiento retirado en otra pestaña y retorno a una pestaña suspendida: bloquear y limpiar sin restaurar permiso viejo; tareas 3 y 4.
5. Efectos React repetidos, registro de página obsoleto y query con datos personales: no duplicar ni filtrar; tareas 2–4.
